# 色と背景の比較案

2026-09-05。v09051652で「INKの配色＋CURRENTの背景模様」を採用。

比較ページ: `/docs/color-review.html`。HOME/TABLE と PHONE/PC を切り替え、現在のデザインと4案を比較できる。「この配色で遊ぶ」は開発サーバーの実際のアプリを開く。

## デザインの基準

既存のXY Pokerを主な基準とし、配置、Vectura、角ばったカード・ダイス、塗りつぶしスート、ショーダウンの構成を維持する。今回は主に色、背景、光沢を変更する。

[ポーカーチェイス公式サイト](https://poker-chase.com/)の表示を確認した。紫の背景、金色のロゴ、発光する装飾が強い印象を作っていた。新しい案では、XY Pokerの縦横の盤面と物理的なカード・ダイスを起点に背景を作る。参照元の画像・ロゴは使用しない。

| 案 | 色と背景 | 目指す印象 |
| --- | --- | --- |
| A · INK（採用） | 墨色、朱赤、白。CURRENTの斜めの枠と細い線 | 配色を変えながら、既存の背景構成を保つ |
| B · PAPER | 白い紙、コバルト。細い罫線と版の位置を示す十字 | 明るいボードゲーム。白いカードには枠と影を残す |
| C · CLAY | 赤土色、生成り、焦げ茶。段状の色面と細い刻み | 温かい素材感。光の演出に頼らず色面で印象を作る |
| D · SLATE | 石板色、ライム。5列の面と刻み | 硬い道具のような質感。操作と選択中の場所をライムで示す |

各案は主背景、盤面、操作面、文字、選択色を別々に指定する。対戦中は背景よりカードを目立たせ、スートやランクの色は維持する。金属調のロゴ・ボタンは単色にして、背景と装飾の競合を減らす。

採用した背景はCURRENTのCSSを再利用し、枠の角度・位置・線の構成を保って色を置き換える。PAPER・CLAY・SLATEの比較用背景は `src/previews/backgrounds/` のオリジナルSVG。フォントの扱いは既存のPNG生成方式を維持し、固定文字はPNGのアルファをCSSマスクとして再利用する。

## 実装範囲

- `src/uiPalette.ts` が通常の配色をINKに設定する。開発時は `?palette=current|ink|paper|clay|slate` で比較できる。
- `src/Palette.css` が採用色と共通の配色ルールを持ち、比較候補のCSS・SVGは開発時だけ読み込む。
- TABLEは対戦画面の実コンポーネントを使った静止サンプル。各案で同じカード・ダイス・選択状態を表示する。
- 通常の盤面はINKに揃え、ほかの盤面スキンの色は維持する。

## 確認結果

ホームと対戦サンプルの390×844・740×900をレンダリングし、比較ページは320px・1280px・1440px幅で確認した。PAPER案では実際のAI対戦を開始し、選択カードと配置先が同じ青で示されること、カードを配置できることを確認した。

主要な文字・ボタンの前景と背景の組み合わせは4.5:1以上。比較案の段階でlint、74件のテスト、TypeScript/Viteビルドを通過した。
