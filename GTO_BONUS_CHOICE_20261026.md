# Bonus draw versus deferral diagnostic (2026-10-26)

A bonus-taking placement was not uniformly better in the tested terminal continuations. This does not identify the bonus draw's isolated causal effect: the candidate card and column also differ. No learning-method or production change is adopted.

Before outcome execution, the plan fixed the first four distinct saved self-play deals at/after game 14,020, their seat mirrors, frozen 14k model, and first eligible prefix among 9/13/17 actions. Eligibility required both bonus-taking and nonbonus legal actions. Every attempted prefix is retained. First two deals are selection, last two confirmation; no outcome-based filtering or adjustment. These are correlated, previously learned training deals, not new strength-evaluation deals.

Each root used one unchanged learned-prior search with 128 simulations / 8 common sampled worlds. Within each class, choose the highest visit-probability action, then original prior and action ID for ties. A bonus action completes a column before the opponent; its own bonus counter increases exactly one. Deferral means no immediate bonus, not necessarily a permanent decision to forgo that column. Both seats then use the existing isolated, stateless diagnostic A9: fixed clock, 64 completed belief samples, each proof capped at 1,000,000 instrumented work units, incomplete proof results discarded. This is different from production time-limited A9 and is not equal learner/A9 computation. Terminal continuations use the saved full state, not eight independently continued hidden worlds.
