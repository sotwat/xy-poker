The matching teacher-opponent rows all carry +1. This is an intended provenance distinction, not evidence that the teacher action loses or that the code assigns the wrong actor's outcome. The source audit of train.py confirms: advice replaces the policy target with teacher one-hot, while the actual action is sampled from learner search; after the game, z is the observed return of the sample actor. Value is a state-only scalar, policy loss is masked CE and value loss MSE with equal coefficients. The source/source-policy identifier is not an input to this critic. State value for the behavior-policy mixture is not teacher-action Q and not automatically the value of an all-teacher continuation. Both factual value supervision and teacher imitation can be legitimate separate objectives; their co-occurrence is not mathematically contradictory. Do not flip negative advice labels to wins, assume score margin is being trained as value, or add source labels at inference without a defined deployment policy.
